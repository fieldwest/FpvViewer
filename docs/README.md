# FpvViewer - 低予算・高性能自作デジタルFPVシステム

RCカーの運転席へ、ようこそ。  
**FpvViewer** は、RCカーライフをより楽しく・刺激的なものにするために生まれた、**「低予算」かつ「高性能・超低遅延」な自作デジタルFPVシステム**です。

ラジコンを外から眺めて操縦する「三人称」の世界から、自分がマシンのコックピットに乗り込んでアクセルを踏み込む「一人称」の世界へ。  
高価な専用ゴーグルや高額な機材を買わなくても、手持ちの Android スマホと安価なシングルボードコンピュータで、誰でも手軽に本格的なデジタル FPV 走行を楽しめる環境を目指しています。

## 🏎️ FPV とは？

**FPV** とは、**First Person View（ファースト・パーソン・ビュー ＝ 一人称視点／主観視点）** の略語です。

RCカーやドローンなどの模型機体に小型カメラを搭載し、そのリアルタイム映像を手元のモニターやゴーグルで見ながら操縦するスタイルのことを指します。

- まるで**実車のドライバーズシートに座って運転しているような圧倒的没入感**
- 地面スレスレの視点から感じる、実車以上のスピード感と迫力
- コーナリング時のクリッピングポイントやタイヤの限界を視覚で感じる新しい操縦体験

### ⚠️ 日本国内における「一般アナログFPV機器」のもう一つの罠：アマチュア無線免許と技適問題

ネット通販等で見かける 5.8GHz 帯のアナログ FPV 送信機（VTX）は、そのほとんどが海外製であり、**日本の「技適マーク（技術基準適合証明）」を取得している製品は皆無に近いのが実情**です。

技適のない送信機を日本国内で無断運用すると、**電波法違反（1年以下の懲役または100万円以下の罰金）** の重大な罰則対象となります。合法的に運用するためには、
1. **「第4級アマチュア無線技士」以上の国家資格** を取得する（講習会・受験料で約1〜2万円）
2. 送信機の送信系統図を取り寄せ、保証機関（TSSやJARD）で **保証認定** を受ける
3. 総務省総合通信局へ **アマチュア無線局の開局申請** を行い、コールサインを取得する

という、**金銭的にも手続き的にも極めて高いハードル**（申請から開局まで数週間〜数ヶ月）を越えなければなりません。

## 💡 ハードウェア選定：なぜ Raspberry Pi 3B+ なのか？

車載する送信機（SBC: シングルボードコンピュータ）には、あえて最新の Pi 4 や Pi 5 ではなく、**Raspberry Pi 3 Model B+（Pi 3B+）** を推奨・採用しています。

### 1. 中古市場での圧倒的なコストパフォーマンス
Raspberry Pi 3B+ は、メルカリ、ヤフオク、中古PCショップ（秋葉原等）などの**中古市場で3,000円〜5,000円前後**と、非常にリーズナブルに入手可能です。万が一のクラッシュや転倒のリスクが伴う RC カー搭載機として、壊れても精神的・金銭的ダメージが少ない「攻めた走り」ができます。

### 2. 消費電力と発熱のバランスが RC カーに最適
最新の Pi 4 / Pi 5 は処理性能が高い反面、発熱が激しく大電流を消費するため、強力なファンや大型バッテリーが必要になります。  
その点、Pi 3B+ は発熱・消費電力が控えめで、RC カーの限られたスペースや電源環境にベストマッチします。

### 3. ハードウェア H.264 エンコードの安定性
Pi 3B+ の GPU（VideoCore IV）には成熟した H.264 ハードウェアエンコーダが搭載されており、軽量な OS（Raspberry Pi OS Lite）と組み合わせることで、低消費電力ながら安定した 60fps 低遅延ストリームを生成できます。

## 🛠️ システム構成とアーキテクチャ

```text
[ RCカー車載ユニット ]                                   [ 手元（操縦者）]
+-----------------------------------+                 +------------------------------------+
|  カメラ (CSI / USB)               |                 |  Android スマートフォン             |
|    ↓ (生フレーム)                 |                 |                                    |
|  Raspberry Pi 3B+                 |                 |  FpvViewer アプリ                  |
|    ├─ rpicam-vid (H.264 60fps)    |                 |    ├─ DatagramSocket (UDP 5000)    |
|    ├─ GStreamer (UDP送信)         |  Wi-Fi 2.4GHz   |    ├─ Annex-B NAL アセンブラ       |
|    └─ NetworkManager (APモード)   | --------------> |    ├─ MediaCodec (Low Latency HW)  |
|         SSID: FPV-AP-XXXX         |   (生H.264 UDP)  |    ├─ SurfaceView (直描画)         |
|         IP: 192.168.4.1           |                 |    └─ リアルタイムHUD / コマ落ち解析|
+-----------------------------------+                 +------------------------------------+
```

### 超低遅延への徹底的なこだわり
1. **プロトコルオーバーヘッドの排除**: RTSP、HLS、WebRTC 等のバッファリングやハンドシェイクを嫌い、**「生 H.264 パケットの UDP 直送り」** を採用。
2. **Android ハードウェアデコーダ直結**: 受信したパケットを自前で NAL 復元し、Android の `MediaCodec`（`KEY_LOW_LATENCY = 1`）へダイレクトに流し込むことで、描画遅延を極限まで圧縮。
3. **テレメトリ ＆ コマ落ち監視 HUD**: 画面ダブルタップで FPS、ビットレート、Wi-Fi 電波強度（RSSI）をリアルタイム表示し、映像の途切れ（Stall）を科学的に分析可能。
